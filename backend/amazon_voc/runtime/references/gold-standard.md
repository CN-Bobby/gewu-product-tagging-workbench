# 人工金标准与 F1 验收

自动回归使用确定性模拟模型，仅证明程序行为、数据契约和报告门禁，不证明语义准确率。

语义验收须由人工根据原始评论独立标注至少 100 条独立评论。标注者不得查看被测系统的预测后再复制其标签；金标准须保存版本、标注说明和人工复核记录。多个事件时逐事件标出可定位引文及核心标签。

```json
{
  "category": "品类",
  "events": [{
    "gold_event_id": "G-000001",
    "review_id": "评000001",
    "evidence_quote": "可在输入原评论中定位的片段",
    "labels": {
      "audience": ["标准人群"],
      "scenario": ["标准场景"],
      "motivation": ["标准动机"],
      "task": ["标准任务"],
      "pain": ["标准痛点"]
    }
  }]
}
```

运行：

```bash
python scripts/evaluate_gold.py --workdir <revision目录> --gold <gold.json>
```

评估器输出事件 precision/recall/F1、各命名空间标签 F1 与宏平均 F1、无依据推断率和确定性门禁状态。语义验收门槛：事件 F1 ≥ 0.85、核心标签宏平均 F1 ≥ 0.80、无依据推断率 ≤ 2%，且确定性质量门禁全绿。独立标注集未准备或未达到最低规模时，应标记语义验收未完成，不得用模型自身结果替代。
