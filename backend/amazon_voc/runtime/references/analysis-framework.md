# V4 分析速查

## 主线

`一个评论 Excel → 评论事实与语义事件 → 人群 × 场景 × 动机 × 任务 → 独立评论频率 → 细分内需求 → 动态旅程 → 评论洞察报告`

只分析输入工作簿评论行。只保留一套正式细分；画像、类 KANO 推理和旅程均从评论事件派生。外部资料不补充事实，不生成开发建议。

## 快速判断

- 人群：谁在执行任务，以及哪些明确的角色或能力限制稳定改变任务；
- 场景：什么情境改变约束或成功标准，而不是只写地点；
- 动机：为什么此刻要完成任务，推断须有评论证据；
- 任务：用户想取得什么进展；
- 痛点：任务被阻断、产生风险或明显成本；
- 痒点：任务可完成但体验仍有落差；
- Workaround：用户为恢复任务目标采取的额外补偿动作。

## 频率与输出

正式细分以独立评论出现率判定，默认最少 `max(2, ceil(有效评论数 × 0.5%))` 条评论。低频组合进入探索区；ASIN 和事件数只作辅助。HTML 六模块、Excel 十二张表，使用相同 `analysis.json` 与质量门禁。

报告仅代表当前评论样本，不外推全市场份额或未观察到的市场机会。
