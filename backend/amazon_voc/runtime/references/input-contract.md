# V4 单工作簿输入契约

## 唯一数据输入

每次分析只接受一个 `.xlsx` 或 `.xlsm` Amazon 评论工作簿。命令行只提供一个 `--reviews` 文件；Web 表单/API 拒绝额外文件。工作簿中的统计汇总和产品评论统计页不作为分析样本或评论数来源，唯一有效行来自评论明细页。

至少需要识别 ASIN 与评论正文。评论标题、星级、日期、变体、产品标题、链接和排名为可选字段。支持列位置变化以及别名映射。工作台导出示例：工作表 `全部评论`，字段 `ASIN`、`商品标题`、`评论日期`、`星级`、`评论标题(EN)`、`评论内容(EN)`、`评论标题(中文)`、`评论内容(中文)`；正文优先采用英文正文列（若表头顺序上英文列在前），否则采用首个匹配的评论正文别名。

通用别名包括：

| 规范字段 | 常见列名 |
|---|---|
| ASIN | ASIN、来源ASIN、产品ASIN |
| 商品标题 | 商品标题、产品标题、标题、商品名称 |
| 评论标题 | 评论标题、评论标题(EN)、评论标题(中文)、Review Title |
| 评论正文 | 评论内容、评论正文、评论内容(EN)、评论内容(中文)、评论原文、Review、Content、正文 |
| 星级 | 评分、星级、Rating、Star、评论星级 |
| 评论日期 | 评论日期、日期、Date、评论时间 |
| 变体 | 变体属性、变体、Variant、尺码颜色 |

优先选择 `全部评论`、`评论明细`、`评论详情`、`Reviews` 等明细工作表名。若工作簿只有一个工作表且名称不匹配，则按该唯一工作表解析。无法识别 ASIN 或正文时应停止并展示缺失列，不得从汇总页猜造评论记录。

## 任务设置

`marketplace`、`country`、`language`、`category` 和正式细分门槛是任务元数据，不是额外分析数据源。它们写入 `master.json`，不得用于补造评论事实。默认最低独立评论出现率为 0.5%，最少两条评论。

产品主表、产品计数、ASIN 数、评论分母均从有效评论行计算。工作簿内预先汇总的数字仅可忽略，不可覆盖明细数据计数。

## 稳定 ID 与隐私边界

ASIN 为产品主键；评论和事件拥有稳定 ID。评论原文留在受控过程数据和 Excel 证据表中，HTML 只展示可定位的短引文，不嵌入完整评论。API 密钥只读环境配置，不得写入缓存、报告或日志。
