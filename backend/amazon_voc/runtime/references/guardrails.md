# V4 确定性质量门禁

## 输入与分析门禁

1. 每次运行恰有一个 `.xlsx` 或 `.xlsm` 评论工作簿；必需的 ASIN 与评论正文列可识别。
2. 评论和产品计数仅由明细评论行计算；不从汇总页或任务设置补造数据。
3. 评论明细存在且清洗后非空；重复处理、缺失字段及评论处理覆盖有记录。
4. 每个事件有唯一 ID、评论 ID、ASIN、证据片段和生成元数据；引文能在对应评论原文中定位。
5. 推理动机有评论事件依据，事实与推理分开；未被评论支持的人群、场景和原因保持空白。
6. 只有一套细分，细分键恰好为人群、场景、动机、任务；每个事件恰好进入一个细分。
7. 正式或探索状态只由独立评论数和已记录的任务门槛判定。
8. 动态旅程阶段 ID、顺序和定义完整；每个事件恰好映射一个阶段。
9. 分析证据范围标记为 `uploaded_review_workbook_only`；输出不得包含外部证据或产品建议数据。
10. HTML 恰有六个一级模块；Excel 恰有十二张规定工作表；HTML、Excel、JSON 的评论、事件、细分数量一致。

质量报告保留结构、处理覆盖、证据、语义、词典、细分与旅程唯一分配、输出一致性七层检查。编译前门禁失败时不生成最终报告；输出检查失败时任务不得标记 completed。

## 禁止

- 在一次分析中接受第二个数据文件或把汇总页当作评论样本；
- 读取 Alexa、Customer Say、产品页面、竞品或其他站外资料；
- 外部搜索、外部补全或生成产品开发建议；
- 固定品类的人群、场景、旅程或 Kano 标签；
- 从地点、Buyer、单项需求、产品属性、星级或单条评论直接创建正式细分；
- 用模型常识冒充评论事实；
- 把类 KANO 推断称为正式 Kano 调研；
- 在 HTML 中嵌入完整评论原文；
- 把“本次没有观察到”写成“市场不存在”。

## 语义评估

自动回归使用确定性的模拟响应，不以此证明语义准确。语义门槛只用独立人工标注集计算：事件 F1 ≥ 0.85、核心标签宏平均 F1 ≥ 0.80、无依据推断率 ≤ 2%。不得从被测系统的输出生成金标准。
