# SOP V5 与 V4 方法兼容性

本说明记录哪些通用评论分析定义可用于单工作簿 VOC 分析。吸收可由评论证据支持的方法定义；不得把外部研究或产品方案建议带入当前流程。

## 吸收的定义

| 概念 | V4 落点 |
|---|---|
| Buyer 与 User 分离、物理限制、熟练度 | 事件 `audience` 字段及动态人群归纳 |
| 场景包含环境压力、动作流、社交与情绪背景 | 事件 `scenario` 字段及动态场景定义 |
| JTBD 表达情境、任务和期望结果 | `motivation`、`task`、`experience` 与 JTBD 语句 |
| 功能、情感和社交任务 | `task.functional_job / emotional_job / social_job` |
| Workaround 是恢复任务目标的额外补偿动作 | 事件提取后在细分和旅程聚合 |
| 使用前、中、后代表生命周期 | 作为理解评论动作顺序的例子，不作为固定阶段 |

## 改写与排除

- “So What” 可检查洞察是否容易理解，但不能判定事实是否成立或细分是否存在。
- L1/L2/L3 改为本任务动态词典，不复用固定品类标签树。
- 频率和星级用于分开描述；细分晋级只看独立评论出现率。
- Workaround 信号词帮助召回，最终必须回到评论中的额外动作、目标和成本。
- 本阶段不接收产品、竞品或站外证据，不产出产品/营销建议或方案缺口判断。
- 国家或市场差异只能描述工作簿评论可支持的内容，不能以刻板印象补写。

不得以星级、情感、地点、Buyer 身份、单个痛点或单条评论直接创建正式细分；不得把外部样本混入评论频数。类别名称、人群数量和旅程阶段不能成为通用源码常量。
