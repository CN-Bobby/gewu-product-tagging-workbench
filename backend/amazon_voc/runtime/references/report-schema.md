# V4 报告契约

`cache/analysis.json` 是 HTML 与 Excel 的唯一分析源。报告构建器不得重新分群、生成画像或改变统计口径。所有证据来自输入评论工作簿。

## HTML 六模块

1. **数据与方法概览**：市场、品类、评论/事件/ASIN/标签数量、处理覆盖率、细分门槛、模型、Prompt、质量摘要和评论证据范围。
2. **全部细分总览**：正式与探索性细分的四维主键、独立评论数、出现率、事件数、ASIN 数和 JTBD。
3. **全部细分详情**：完整展示每个细分的画像摘要、证据强度、痛痒点、期望、类 KANO 推理及 Workaround。
4. **细分横向比较**：比较人群、场景、动机、任务、需求与 Workaround。
5. **动态用户旅程**：展示当前样本生成的阶段、动作、目标、障碍、缺席与细分差异。
6. **探索性信号**：呈现低于正式门槛的需求组合，并明确其探索状态。

支持筛选、搜索、多细分比较、展开与打印。HTML 不嵌入完整评论原文；引文应短且能回到评论 ID。

## Excel 十二张表（固定顺序）

1. 任务与方法说明
2. 产品主表
3. 清洗后评论
4. 评论处理覆盖
5. 语义事件
6. 动态标签词典
7. 事件标签映射
8. 正式与探索细分
9. 细分需求
10. 动态旅程
11. 证据索引
12. 质量门禁

不生成外部补全或 AI 产品建议工作表。所有工作表冻结首行、启用筛选并为长文本换行。HTML、Excel 与 JSON 使用相同的评论范围、分析对象及门槛，所有计数必须一致。详细模型调用日志只保存在 SQLite、Web 与 `model_calls.json`。
