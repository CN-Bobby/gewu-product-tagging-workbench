# V4 评论量化口径

## 样本范围

有效评论总数只由上传工作簿的评论明细行清洗、去重后得到。工作簿中的汇总数字、产品评论统计、外部资料和模型生成行均不作为分母或证据。

## 细分主指标

`细分评论出现率 = 命中该细分的独立评论数 ÷ 有效评论总数`

同一评论拆成多个事件时，在同一细分中只计一次。默认晋级门槛为 `max(2, ceil(有效评论总数 × 0.5%))`。低于门槛的组合标记为探索性。事件数、ASIN 数、星级和情感仅作为辅助描述，不参与晋级。

## 细分内部指标

| 指标 | 口径 |
|---|---|
| 痛点评论数 | 至少一个事件出现该痛点的独立评论数 |
| 痒点评论数 | 至少一个事件出现该痒点的独立评论数 |
| 期望结果评论数 | 至少一个事件出现该期望的独立评论数 |
| Workaround 评论数 | 至少出现一次明确补偿动作的独立评论数 |
| 负面评论数 | 至少含一个负面或混合事件的独立评论数 |
| 旅程阶段评论数 | 映射到动态旅程阶段的独立评论数 |

报告显示分子和分母。评论出现率描述当前上传样本，不能写成市场份额。

## 星级与情感

星级只作为评论背景；事件情感依据具体表达。可描述负面率、正向体验和严重程度，但不得用“频次 × 星级”决定细分成立与否。
