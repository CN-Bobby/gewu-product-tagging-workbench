# 护栏：文案禁区、证据规范与验收清单

## 1. 输出文案约束

禁止空泛表述（出现即验收不通过）：

- "市场潜力巨大"
- "竞争非常激烈"
- "建议差异化"
- "可以加大广告投入"

必须改写为带证据的结论，推荐句式：

> `sourdough proofing basket` 当前搜索量为 X，购买率为 Y，点击集中度为 Z，过去 12 个月同比为 W，因此判断为……；但该结论尚未包含评论和成本数据，置信度为中。

不得输出：具体广告分组、否定关键词列表、Listing 布词、具体建议出价、未提供利润数据时的 ACOS 判断、未提供销量和供应链周期时的备货数量。

## 2. 证据与置信度规范

每条重要结论必须：

- 引用至少 3 类证据字段（搜索量/趋势、相关度、购买率、集中度、PPC/竞争指标中的至少三项）；
- 标记置信度：高（多字段多词共同支持）/ 中（有数据但有语义或样本限制）/ 低（主要依赖语义推断）；
- 涉及产品功能的结论标记"假设"，并指明验证路径（评论、竞品页面、供应链）。

## 3. V1 范围边界（越界即错误）

不做：① ASIN/Node 关键词重叠、内部蚕食和组合关系分析；② Listing SEO 标题/五点/后台词布词方案；③ 广告分组、匹配方式、否定词和具体投放方案。

保留：数据中的来源 ASIN/Node 字段（供审计和未来扩展）；当前 PPC 作为市场获客成本和竞争压力指标（不转化为广告建议）。

## 4. 异常处理红线

- 缺失值留空，永不填 0；趋势缺月不插值。
- 指标冲突不静默覆盖：保留最新快照，差异明显时记录最大/最小及更新时间。
- SellerSprite本地调用默认≤30次/滚动60秒且相邻调用≥1秒；服务端限流仍需等待并按配置时长重试。限流等待不得被误判为失败。新计划MCP临时错误全任务最多自动重试10次、单请求最多1次；旧计划沿用记录额度或兼容默认2次；权限/额度/参数错误不重试。`ERROR_UNAUTHORIZED` 统一记录为“授权或额度拒绝”，只有账户状态或用户确认后才能细分原因。
- 自动补调用上限 2 次，超出必须先问用户；**连续 2 次返回空/0 条即判定为参数模式错误**，停下来核对 schema（product_research 正确参数模式见 mcp-routing.md §3），不得换参硬试。
- 任何截断、过滤失效、缺月、补调用都必须进 `12_数据质量` Sheet 并评估"是否影响结论"。
- **报告一次性生成**：最终 xlsx 只能由 build_excel_report.py 产出，禁止事后手工追加图表/改 Sheet；展示层有任何调整需求，改脚本或模板后基于缓存重跑。

## 5. 验收清单（交付前逐项自查）

1. 支持 M1（ASIN+Node）/ M2（多 ASIN）/ M3（纯 Node）/ M4（单 ASIN）四种输入模式，报告口径标识正确；
2. 执行前准确估算调用量并获用户确认（>30 次）；
3. 每 20 个 ASIN 自动分批；
4. Skill不设置20-ASIN硬上限；超过20个时展示批次数、调用量与预计等待时间后确认，禁止静默截断；
5. 自定义 `data_month` 只传给 product_research / traffic_extend；traffic_keyword不传month并固定当前第1页；趋势仍截止最新共同完整月；
6. Node 榜单结果经过本地 BSR 复核；
7. 点击集中度与转化集中度字段不混淆；
8. 中文翻译经过语境校正（含 proofing basket / banneton 类已知错译）；
9. 多标签分类完成：需求标签、流量性质和流量性质理由完整；购买意图为中文枚举；除品牌/错类/泛流量优先项外，含 audience 标签必须为人群长尾；核心大词不得带人群/材料/功能/规格/场景/套装/配件标签；`validate_labels.py` 全绿；
10. 默认选择 5 个核心词和 5 个代表长尾词；
11. 每个趋势词只调用一次历史接口；
12. 只拉历史月搜索量，不拉历史 PPC；
13. 后续转置和图表不重复调用；
14. 报告同时包含宽表和长表；
15. 结论附数据证据和置信度；
16. `07_产品方向` 每行有来源关键词、数据证据、推断、假设、置信度和待验证项；未被关键词支持的材料/功能/规格不得输出；`validate_analysis.py` 全绿；
17. 不做量化蚕食分析、SEO 布词和广告分组；M1 的来源对比（共有词/市场缺口词/本品差异词）必须呈现；
18. Excel 可筛选、可复制、可做透视表；
19. 缺失值不填 0；
20. 实际调用日志完整；固定三页的标准20-ASIN M2为33次、Sorftime为0；新计划临时错误重试≤10次，硬上限=max(200,计划调用+10)；
21. 枚举列全部中文落地（流量性质/生命周期/象限/机会类型/标签前缀）；
22. 每个直接输入ASIN只调用一次当前 `traffic_keyword` 第1页，同次生成两个矩阵；没有第2页或Sorftime冗余调用；
23. 报告由build_excel_report.py一次生成，13个Sheet名称及顺序固定为00–12；有效散点数据时看板恰为2张折线、1张柱状、1张散点，无有效数据时用明确提示替代空图框；散点按核心/精准、人群、其他长尾分组并使用动态局部轴；两张折线图例为真实关键词且同词同色；
24. 两张趋势图的每个系列都显式绑定连续24个月 `yyyy-MM` 分类轴，横轴隔月显示标签且不得退化为1–24序号；ABA Rank图反向纵轴，Rank 1在顶部；缺月不补0；
25. 文件名符合 `{站点}_{品类标签}_{口径}_{YYYYMMDD}.xlsx`；
26. M4 模式结论已降级并建议补 Node；M1 模式结论包含市场面×本品对照；
27. `validate_report.py` 全部 PASS。
