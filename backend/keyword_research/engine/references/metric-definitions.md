# 指标与字段口径

## 2. 字段禁区（违反即验收不通过）

1. 缺失字段留空，**不得填 0**。
2. 不得用 `purchaseRate` 代替转化集中度；存在 `top3ConversionRate` 时不得自行估算。
3. 不得把 `trafficPercentage` 解释为整个市场份额。
4. 不得把同义词/近义词搜索量简单相加并称为"市场容量"；需求体量用中位数、分位数或"需求体量指数"表达。
5. 多站点数据不得直接相加；PPC 保留站点原币种。
6. 同义词归入同一词族，但原始关键词行必须保留（真实搜索表达与广告价值不可丢）。
7. `rankPosition` / `adPosition` 是对象：缓存保留page/index/position；矩阵按用户要求展示page/index，不得从全局position或固定页容量反推页码。
8. `ABA rank` 是市场关键词月度搜索频率排名，与某 ASIN 的自然位/广告位不是同一指标；两者不得混用。

## 3. 24 个月趋势指标（analyze_trends.py 计算）

对齐规则：以各成功词最新月份中的最早者作为共同截止月，向前生成连续24个自然月。某词缺月只在该词该月留空，不得从全体横轴删除。

对每个词计算：

| 指标 | 公式/说明 |
|---|---|
| 最新月搜索量 | 序列最后非空月 |
| 24 个月均值 / 中位数 | mean / median（忽略空月） |
| 最新月环比 MoM | 最新非空月 / 上一自然月 − 1；上一自然月缺失则空 |
| 最新月同比 YoY | 最新月 / 12 个月前同月 − 1（缺月则空） |
| 最近 3 / 6 个月增长率 | 末值 / 区间首值 − 1 |
| 12 个月同比累计变化 | 最近 12 个月合计 / 之前 12 个月合计 − 1 |
| 标准差 / 变异系数 CV | pstdev / mean；CV 衡量波动 |
| 峰值月份与峰值 / 谷值月份与谷值 | max / min 及对应月份 |
| 峰谷比 | 峰值 / 谷值（谷值为 0 时留空） |
| 连续增长月数 | 从最新月向前连续环比为正的次数 |
| 首个明显增长拐点 | 连续 ≥2 个月环比增长且此前 3 个月平稳/下降的第一个月 |
| 需求是否连续两年重复 | 两年季节指数曲线同月符号一致性 |

首页同时展示同一批核心/长尾词的搜索量和 ABA Rank 折线。两图月份、系列顺序和颜色必须一致；ABA Rank 纵轴反向显示，Rank 1 在顶部。缺月均保留折线缺口，不补 0。

## 4. 季节指数与旺淡季阈值

```
季节指数 = 当月搜索量 / 24 个月月均搜索量
```

| 季节指数 | 判定 |
|---|---|
| ≥ 1.30 | 明显旺季 |
| 1.10–1.29 | 偏旺 |
| 0.90–1.09 | 常态 |
| 0.70–0.89 | 偏淡 |
| < 0.70 | 明显淡季 |

阈值允许按品类特征在报告中调整，但必须公开调整理由。

## 5. 集中度"高/低"判定

点击—转化集中度象限的高低**默认按当前词池的中位数（或分位数）判定**，不使用跨品类固定绝对阈值；报告必须显示实际数值与中位数基准。

## 6. 置信度定义

- **高置信**：多个数据字段 + 多个关键词共同支持；
- **中置信**：有明确数据，但存在语义或样本限制；
- **低置信**：主要依赖语义推断，需外部验证。
