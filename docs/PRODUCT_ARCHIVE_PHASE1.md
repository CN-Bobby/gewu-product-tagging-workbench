# 选品档案与项目闭环第一阶段

## 页面和项目

- `#/product-archive` 可关联打标模块的既有 Dataset，也可导入 SellerSprite `.xlsx` 并选择已有项目或新建项目。
- `#/product-archive/{archive_id}` 按产品/市场概况、市场体量、竞争结构纵向呈现；顶部只显示站点、品类、月份、样本量与映射状态，并有“查看样本”入口。
- `#/product-archive/{archive_id}/samples` 承载 Dataset 切换、Excel 导入、字段确认、只读预览、重复/缺失提示、ASIN 筛选、行选择和下游任务入口。原始样本不编辑、不删除、不自动去重。
- 选品档案使用打标工作台的 `Workspace`。源 Excel、Data X 导出、档案记录、关键词输入/计划/结果、评论导出与原始响应、VOC 输入及最终报告，复制或登记在 `<数据目录>/projects/<workspace-id>/` 下。模块原有文件仍保留；历史文件只做索引，不搬移。
- `/api/projects/{id}/files` 返回项目文件夹类别、计数和文件校验信息；档案主页面展示文件名、类别、哈希前缀与可下载副本。项目文件按 SHA-256 命名和校验。

## 样本与下游任务

- 确认字段映射会冻结 Dataset 哈希、原始行摘要、样本行数和映射修订；发现源数据变化时要求重新确认。
- `ASIN` 作为档案统计的商品实体键，重复 ASIN 仅在指标计算时按最大月销量保留一行；原始样本仍完整可查。
- `商品详情链接` 是独立映射字段。选定样本推送关键词或评论任务前，服务端要求映射快照已确认，并默认从该行详情链接解析子 ASIN；未选择“仅使用子 ASIN”时才允许回退到原始 ASIN。不同 Dataset 的记录不能混入当前档案任务。
- 关键词任务按最多 20 个 ASIN 分组，关闭逐 ASIN 流量矩阵。评论任务按显式选择的 ASIN 创建，策略可设为仅完整成功后自动创建 VOC，或部分成功但有有效导出评论时也创建。评论 Excel 通过来源任务 ID 与工作簿 SHA-256 保证 VOC 交接幂等；没有有效工作簿或没有评论时不创建 VOC。
- Amazon Reviews 的接口口径是每个 ASIN 最多两次相同站点的 `Both` 请求；这是重复调用，不是分页。Sorftime 工具每次最多返回 100 条、时间范围为最近一年，不能描述为全历史评论。
- 评论来源 VOC 的 HTML 与 Excel 报告包含请求 ASIN 数、已完成数、有评论并进入分析数、空评论数、失败/未完成项与时间/接口范围；评论任务和 VOC 产物登记回来源 Workspace。

## 指标口径

- 月销量只加总可解析的非负值；销售额逐行优先使用原表值，缺失时可用价格 × 月销量估算，并标记估算或混合口径。缺失不补齐。
- ASIN 与品牌集中度分别显示销量和销售额 Top 3、Top 10 占比。销售额缺失时相应占比保持空值，不以销量冒充销售额。
- 卖家国家/地区、履约方式、评分数、评分星级、价格、上架时间同时显示销量占比与商品链接数量/占比；链接占比的分母是当前筛选样本的商品记录数，销量占比的分母是有数值的样本销量合计。不可解析值与空值分开显示。
- 评分数固定区间：`0–100`、`101–500`、`501–1,000`、`1,001–5,000`、`5,001+`。
- 星级采用不重叠半开区间：`[0,3.7)`、`[3.7,4.0)`、`[4.0,4.3)`、`[4.3,4.7)`、`[4.7,5]`。超出 0–5 范围的数据列为不可识别。
- 价格按站点货币分箱：`[0,5)`、`[5,10)`、`[10,15)`、`[15,20)`、`[20,25)`、`[25,30)`、`[30,35)`、`[35,40)`、`[40,50)`；`[50,60)` 起每 10 个货币单位一档。下界包含、上界不包含；负数或不能解析的价格不可识别。价格组合图按原始精确价格排序，用面积图表示销量、折线表示链接数。
- 上架时间按档案数据月份月末（无月份时按确认快照日期）计算：`[0,3mo)`、`[3,6mo)`、`[6,12mo)`、`[1,2y)`、`[2y+]`。未来日期不可识别。
- Data X 标签切片读取当前 Dataset 最近保存的不可变快照，人工值优先于模型值；筛选会重算本页统计，未知标签或过期标签值不会被静默接受。
- 商品图片只读取导入时保存在本地 Asset 的文件，不在页面渲染时远程抓取。Top 品牌最多展示 20 个 ASIN 图片，并按样本销量从高到低排列；点击缩略图可放大查看。
- 页面不生成不透明的综合竞争分。任何样本比例只描述当前筛选样本，不外推为全市场事实。

## 验证与 SellerSprite 真实调用

- 离线回归入口：`scripts/test_product_archive_phase1.ps1`。默认执行档案统计、项目文件、关键词、VOC 交接与前端检查；不触发付费/真实查询。
- 只有在泳衣项目已建立并冻结 10 个子 ASIN 后，才运行脚本的 `-Live` 模式。该模式对 SellerSprite MCP 执行 `initialize + list_tools` 和一次最小 `traffic_extend` 请求，不自动重试；开始前写一次性标记。日志不得写入 Key 或完整 ASIN 清单。
- SellerSprite `secret-key` 只从实例 `keyword-research/credentials.env` 加载。连接/初始化失败、业务拒绝和成功但无数据分别报告；响应体与密钥不写入验收报告。
- 狗狗发声玩具测试先从 Sorftime US 类目树确认唯一 `Pet Supplies → Dogs → Toys → Squeaky Toys` 叶节点，再对该节点调用一次 SellerSprite Top 50 查询。只有恰好获得至少 50 个唯一 ASIN 才冻结数据和启动下游；不以其他节点补数。榜单响应、评论样本和任务文件只保存在隔离项目，不把完整 ASIN 清单写入日志/验收报告。
