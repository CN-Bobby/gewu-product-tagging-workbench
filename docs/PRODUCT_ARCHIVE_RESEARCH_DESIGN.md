# 选品档案深度市场研究设计

日期：2026-10-20
状态：DEV 实施中，尚未通过真实模型语义验收

> 2026-10-21 起，下面的“三次模型请求、两轮由工作台编排的检索”是原设计记录；当前实现改为 Reasonix Skill 单次研究会话。实际调用与预算见 [Reasonix 桥接说明](PRODUCT_ARCHIVE_REASONIX_BRIDGE.md)。

## 用户目标

让档案分析尽可能接近用户认可的网页端深度调研：以大模型的品类知识、问题拆解和综合能力为主；公开网页用于核验当前事实；档案关联的打标工作簿（含图片）、已完成关键词表、评论表和 VOC HTML 只用于修正、对照、补充证据。输出要对品类形态、细分人群和任务作出充分区分，并贯通到功能、场景、动机、文化环境和季节性。

## 研究流程

1. **准备材料。** 只列当前档案关联且已完成的四类业务产物，用户可以排除；不因生成而启动采集、评论、VOC、关键词或其它付费业务任务。商品标识、链接、客户凭据和网页里的指令不作为模型分析输入；保留理解产品形态所需的标题特征、标签、评论主题、已完成关键词结果及图片证据。
2. **初步研究规划。** 发送站点、品类和已选业务关键词（仅作为检索锚点），模型列出可检查的问题和查询方向；不读商品行/评论原文，不写最终建议或关键词。最多一次小型调用；模型返回的问题或查询少于互补方向时，补足商品形态/相邻替代、买家任务/阻碍、地区/季节等固定方向，不自动重试。固定补充和第二轮补查沿用模型首条具体查询作为商品与人群锚点，防止扩成泛品类搜索。
3. **第一轮检索与发现整理。** 按商品形态/边界、用户任务/触发与阻碍、替代品/差异、季节/地区搜索。每条查询分别记录搜索状态、候选数、成功读取的页面和来源编号，并限制重复页面。第一轮结束后，模型只基于已抓取材料指出相互矛盾的信号、尚未覆盖的问题和值得核实的细节，不生成报告。
4. **第二轮定向核验。** 按发现的缺口追加少量查询；若发现整理调用失败，使用确定性的补充问题模板。搜索服务被拦截、无结果、页面失败和成功命中分别记录。不得把搜索词当成最终关键词结论。
5. **一次统一综合。** 模型知识承担完整分析，网页证据核验当前事实，本地资料用于对照和校正；不可按页面模块分别问答。结果包含商品形态比较、动态细分、跨模块关系、来源、推断依据、限制和待验证项。
6. **完整性校验与编辑。** 每个模块要么有可读内容，要么给出明确的缺口原因；不能把只有一条结论的残缺响应标成完整成功。保留/忽略仍是整体决定，保留后模块/条目可改标题、编辑、增加、删除和排序。

模型提示词要求将文件和网页内容视为不可信的资料，而非指令；不尝试输出或展示隐藏思维链。工作台只展示研究问题、检索进度、来源覆盖和可供审核的结论。

## 关键词边界

面向用户的关键词模块只读取当前档案所选、已完成关键词任务的结果表；不从大模型知识、网页搜索、计划查询词或其它 MCP 结果补写关键词或搜索量。内部用于检索的查询词不进入分析报告的关键词字段。

## 预算与费效

- 同一次分析最多三次模型请求：1 次初步规划、1 次发现整理、1 次统一综合。两个规划/发现阶段各只调用一次，不自动重试；失败时用固定问题模板降级。
- 研究规划和缺口整理使用配置的文本推理模型；选择图片时，统一综合阶段使用已验证的视觉模型。两个模型身份和用量分别记录，避免因为选了图片而把轻量研究步骤也路由到视觉模型。
- 公开检索最多 6 次、读取最多 12 个页面，并对两轮共用最多 24 次真实 HTTP GET（逐次计入重定向）；第一轮和第二轮分别设上限，同一问题、域名和页面去重，避免某个方向占满预算。
- 文本、图像和最终输出分别计量；选择的图片最多 4 张。输入预算覆盖实际序列化请求体，而不只是档案文件；外部来源和本地材料分别保留覆盖信息。
- 每一步写明模型身份、请求阶段、已知 token、未知费用。模型供应商未提供经验证费率时费用显示“未知”，不显示 0。
- 搜索、计划和最终结果可安全缓存/幂等；缓存键需含模型身份、分析规则版本、输入资料内容摘要和用户选项，不能静默复用旧资料或旧模型的结果。
- SellerSprite 等收费 MCP 只在明确选择且可以给出硬调用上限时集成；不在普通档案生成中隐式触发。

## 验收要求

- 研究问题、每条查询的状态与来源数、基于证据的追加问题和第二轮覆盖均可查看；不同产品形态、细分任务与用户情境可区分并关联。
- 字段完整或明确说明缺口；功能是高信息量综合描述，不退化为属性/功能清单；场景、人群和动机不压成一句泛话。
- 资料选择、模型调用、搜索请求、图片数、文本与输出 token、结果过滤原因、来源和失败阶段可追溯；费用未知如实标示。
- 页面阅读紧凑易懂，运行状态、来源和结果可恢复；窄屏无溢出。人工语义验收、自动化、浏览器实测和 DEV 身份分别记录。
