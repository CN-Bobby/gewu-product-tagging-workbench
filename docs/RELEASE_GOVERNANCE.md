# 版本与发布规则

> 本机新功能的日常人工测试统一在 DEV；独立 TEST 服务已停止，旧 TEST 候选链路已退役。当前流程见 [DEV 唯一日常人工测试环境](DEV_ONLY_DAILY_TESTING.md)。

应用版本唯一来源为根目录 VERSION.json。后端直接读取，Vite构建注入界面；npm元数据通过 scripts/sync_version.py 生成，CI使用 --check 拒绝漂移。RELEASE_LEDGER.json记录不可复用的客户版本序列和替代关系。

默认交付顺序为：各开发分支汇总到 DEV → DEV 人工测试 → 用户确认通过 → 冻结版本和构建产物 → 将同一冻结提交/产物提升到 PROD → 核验 PROD 实际身份 → 发布对应 GitHub Release。DEV 是唯一日常人工测试环境，独立 TEST 已退役；不再要求从 ZIP 激活 TEST 才能进入后续发布流程。

冻结记录必须绑定应用版本、完整源码 commit、干净/脏状态、build ID、测试证据、分发包 SHA256 和发布台账。用户确认 DEV 人工测试通过后，方可冻结并推进 PROD。冻结后任何源码或产物变化都必须产生新的未使用版本，禁止覆盖候选或已发布附件。PROD 必须运行与冻结记录完全一致的构建；生产身份未核验前不得称为已发布。

PROD 核验通过后，默认在公开 GitHub 源码仓库创建指向同一源码 commit 的不可移动 tag 和对应 Release，并上传该版本绿色便携 ZIP 及 `.sha256`。GitHub Release 的版本、tag、源码提交、build ID、附件大小和 SHA256 必须与 PROD 发布记录一致；发布说明清晰标注候选预发布或正式发布。只有 PROD 对应版本允许发布到 GitHub，DEV 日常构建不得作为已发布版本。在线更新读取已发布 Release 元数据和附件，不从任意开发分支同步源码。

另一台电脑安装验收、自动化测试、DEV 人工测试和真实外部服务调用分别记录。如果具体版本要求另一台电脑安装验收，则该验收保持独立门禁；不能把它与 DEV 人工测试或 PROD 身份核验合并表述。尚未完成的门禁在台账中保持待验收。

日常开发提交不更新客户版本号；内部开发构建以版本号和Git commit共同标识。准备冻结客户试用/验收候选时，才递增到未使用过的`beta.N`，并同步VERSION.json、RELEASE_LEDGER.json、CHANGELOG.md及派生版本元数据。候选对外发布、交付或冻结后不得覆盖；改变后的替代程序使用新的beta号。

接管基线位于 baseline/takeover，只记录历史代码，不代表已验收发行版。具体 DEV 分支、PROD 目标分支和当前提交每次操作前都要现场核验，不把旧文档中的分支名当作当前目标。`main` 作为对外发布源码线，只能在 DEV 人工验收通过、版本冻结并按流程提升 PROD 时推进。发布标签不可移动，安装包不可覆盖。Git tag 只固定源码提交，不代表 GitHub Release、部署或验收；每项状态必须由对应证据支持。历史源码标签可以追溯补建，但须明确标记为历史源码引用，不能改变原验收结论。

里程碑：0.4.1现有功能收尾 → 0.5.0-alpha.1项目模板、严格复用、独立状态 → 0.5.0-beta.1首次外测 → 0.5.0-beta.2交互安装缺陷版 → 0.5.0-beta.3简化安装候选。只有通过对应验收才能变更release_status，不能靠改版本号宣称完成。

所有任务冻结application_build：应用版本、commit、dirty和源码摘要。Skill独立版本及内容摘要、Reasonix二进制版本及摘要、数据库递增迁移编号分别进入发布清单。商品V1/V2不是软件版本。

正式发布必须来自干净Git树，精确锁定依赖，测试报告绑定commit。内部候选文件名使用`<版本>-candidate.<短commit>`；客户提升文件只含产品名和版本号。客户附件一旦提升即冻结，任何变化递增`beta.N`，禁止使用“修复版、最新版、最终版”或覆盖同版本。构建附件存入releases/<version>，不进入源码Git；已有目录拒绝覆盖。发布清单记录构建时间、操作系统、Python、Skill和依赖版本。测试数据、SQLite、会话、密钥和客户原图禁止打包。

升级前同时考虑数据库与Reasonix会话状态备份。新版在隔离副本验证恢复旧会话ID；失败列为阻塞，禁止静默创建新会话。安装器不得覆盖客户数据；二进制回退必须检查状态格式兼容性。

状态只用：未完成、已实现待验收、已验收、阻塞。进度报告必须写当前commit、实际运行版本、已验收、待办、阻塞和产物路径。历史验收报告保留原日期，不作为新版本验收凭证。
