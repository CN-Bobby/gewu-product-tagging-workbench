# beta.5 实施状态

基线：`0.5.0-beta.4`，开发基线提交 `ca15994295c29c68c2c7b2d94fcd6caac03d4ca1`。

## 已完成

- Ask：单选、多选、文字补充、跳过、格式降级、幂等提交、问题状态和错误归因；同轮最多三个业务问题，回答不等于批准变更。
- 项目与表格：导入时选择或新建项目，失败重试复用项目；顶部按项目筛选工作表。
- 多对话：项目→表格→对话；独立消息、草稿、图片编号、模型/Key和运行会话；回收站、恢复与彻底删除。
- 图片对话：PNG/JPEG/WebP，按钮多选、剪贴板、拖入、只发图片、稳定图号；明确绑定商品后作为补充图证据。
- 模型管理：同服务多个具名Key，手动选择、测试、停用和删除；文本/视觉模型及Key分开配置并冻结到任务。
- 原列续打：接入已有人工标签列，非空值保护、只补空白、异常值待复核、停用/恢复接管、原位置导出。
- 数据兼容：旧单会话迁移为“历史对话”；逻辑迁移复用现有元数据表，桌面升级仍先备份数据库、数据集与会话状态。

## 交付边界

- Key不自动轮换、自动故障切换或分摊并发。
- 榜单截图默认只用于讨论；不会自动切成商品行。
- 商品补充图必须显式绑定；绑定不自动触发批量打标。
- 自动测试验证协议和数据保护，不替代服装、水杯、多组件套装的真实识别质量验收。
- 候选状态保持 `pending_acceptance`，用户完成安装、升级/回退和真实商品案例验收前不标记正式发布。
