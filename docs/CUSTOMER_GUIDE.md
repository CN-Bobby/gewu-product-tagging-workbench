# 格物商品打标工作台使用说明

当前为0.5.0-beta.1候选说明，客户发布以发行清单为准。

1. 运行Windows安装包。程序安装到当前用户的独立版本目录，内置Python、Reasonix和网页，不要求自行安装开发工具。数据与缓存目录在首次打开时单独选择。
2. 点击带版本号的“格物工作台”快捷方式。首次选择数据与缓存目录，浏览器自动打开本机工作台。原表、原图、结果及会话存于数据目录；缓存软上限10 GB，8 GB开始提醒。
3. 在“模型设置”中填写服务名称、HTTPS兼容地址、服务内文本模型、服务内视觉模型及API密钥。模型列表填写服务内名称，例如`deepseek-v4-flash`和`deepseek-v4-flash-vision-exp`，不要填写`deepseek/deepseek-v4-flash`这种已经带服务名前缀的完整引用；工作台会自动显示并使用`服务名/模型名`。密钥只在本机保存，接口不返回密钥。自动视觉标签和图文联合标签属于本版正式功能；每件商品默认读取表格中的一张主图，补充套图继续用于高清查看和人工核对。
4. 导入Excel时先核对识别出的原始表头、图片数量及SKU/标题/参数用途。选择已有项目可以把新月份纳入同项目；每次上传仍是独立数据集。字段名不同不会被强制替换，原始字段完整保留。
5. 导入后即建立工作表和文字底稿任务。可通过“字段用途”指定多列文字共同参与，或在“数据概览”核对全量字段统计和代表样本。
6. 从持续对话提出标签目标，核对提案影响的列、商品范围、证据来源和已有结果处理，一次确认建列并执行。证据来源可选纯文字、商品主图或文字和商品主图。显示列与执行列独立选择；旧标签不会因为仍在表格中显示而自动加入新任务。
7. “标签标准”可保存当前列及必要上游定义；新月份选择同项目标准，可只复制，或一次确认复制并执行。严格匹配必要文字、完整图片像素、规则、Skill和模型配置后才复用。复用人工值有单独标记，点击单元格可看来源；来源不一致会待确认。
8. 打开“任务与局部修复”可汇总多个任务中的失败单元格，无需先在主表逐列筛选。每列保存独立商品范围，确认卡显示失败、实际重跑、保留成功、保护和预计请求。兼容修订只重跑选中失败项；改变语义、区间、结果类型或方法时，后端把实际范围扩到整列并明确提示。尺码数字和年龄分段可切换为零模型请求的确定性规则。
9. 标签构思需要比较款式边界时，在“数据概览”填写观察目标，最多抽取24件代表商品，每组6张不同商品主图同批比较。该观察用于完善标签定义，不会自行建列或打标；正式填表仍按每批5件执行。
10. 双击图片查看原始像素、缩放和切换商品；表格专注隐藏对话区域，行高可统一调整。筛选过的表头会显著标记，筛选摘要可逐列或一次清除。
11. 满意后保存V1。后续编辑仍在草稿，V1保持冻结。导出选择标签列及顺序，原始字段与图片保留；商品标识及来源、状态和证据在AI_Detail，规则在Tag_Dictionary。
12. “存储空间”区分原表、原图、数据库、会话、备份、导出和可清理缓存。清理缓存不删除权威数据。不要手动删除会话目录。

程序仅监听本机。各客户端独立运行；首批不提供云同步、多人协作或跨电脑迁移。升级使用带SHA256校验的离线安装包，网页没有在线更新入口。
