# 格物商品打标工作台使用说明

当前为0.5.0开发验收说明，客户发布以发行清单为准。

1. 运行Windows安装包，选择程序目录。程序内置Python、Reasonix和网页，不要求自行安装开发工具。
2. 点击带版本号的“格物工作台”快捷方式。首次选择数据与缓存目录，浏览器自动打开本机工作台。原表、原图、结果及会话存于数据目录；缓存软上限10 GB，8 GB开始提醒。
3. 在“模型设置”中填写服务名称、HTTPS兼容地址、模型名及API密钥。文本模型放首行；视觉模型名应包含vision。密钥只在本机保存，接口不返回密钥。设置完成后核对文本和视觉模型选择。
4. 导入Excel时先核对识别出的原始表头、图片数量及SKU/标题/参数用途。选择已有项目可以把新月份纳入同项目；每次上传仍是独立数据集。字段名不同不会被强制替换，原始字段完整保留。
5. 导入后即建立工作表和文字底稿任务。可通过“字段用途”指定多列文字共同参与，或在“数据概览”核对全量字段统计和代表样本。
6. 从持续对话提出标签目标，核对提案影响的列、商品范围、覆盖与看图方式，一次确认建列并执行。显示列与执行列独立选择。
7. “标签标准”可保存当前列及必要上游定义；新月份选择同项目标准，可只复制，或一次确认复制并执行。严格匹配必要文字、完整图片像素、规则、Skill和模型配置后才复用。复用人工值有单独标记，点击单元格可看来源；来源不一致会待确认。
8. 局部修复先通过表头或独立筛选入口圈定商品，再选列安排执行。任务详情可以选择失败单元格、修订规则和生成修复提案。“强制重算”会绕过结果及图片缓存并重算已有值，执行后新发生的人工修改仍受保护。
9. 双击图片查看原始像素、缩放和切换商品；表格专注隐藏对话区域，行高可统一调整。筛选过的表头会显著标记，筛选摘要可逐列或一次清除。
10. 满意后保存V1。后续编辑仍在草稿，V1保持冻结。导出选择标签列及顺序，原始字段与图片保留，状态和来源在AI_Detail，规则在Tag_Dictionary。
11. “存储空间”区分原表、原图、数据库、会话、备份、导出和可清理缓存。清理缓存不删除权威数据。不要手动删除会话目录。

程序仅监听本机。各客户端独立运行；首批不提供云同步、多人协作或跨电脑迁移。
