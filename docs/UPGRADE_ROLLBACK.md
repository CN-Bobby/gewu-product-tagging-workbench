# 升级与回退

每个发布安装包有独立版本、Git提交与SHA256；不得用同版本安装包覆盖另一份代码。

升级前停止当前工作台，确认批处理保存完成。安装新版本到默认的独立版本目录，保留旧版本目录与快捷方式。数据目录及缓存目录不属于安装目录，升级或卸载程序不删除它们。

新版首次使用同一数据目录时，若构建提交发生变化，启动入口把SQLite做一致性备份，并备份数据集Reasonix状态。路径为`数据目录/backups/upgrade-时间/`；数据库新增结构还会单独创建迁移前备份。已有原生会话隔离迁移备份位于`backups/session-isolation/数据集ID/会话ID/`。

回退先关闭新版。保留当前数据目录副本，从目标备份恢复workbench.db、datasets目录及installed-build.json，再打开旧版本快捷方式。程序二进制回退不能代替会话状态回退。不要在服务运行时直接复制覆盖SQLite主文件；WAL也可能含未检查点写入。

安装目录内提供离线恢复工具：

```powershell
.\runtime\python.exe .\scripts\restore_backup.py --data "D:\工作台数据" --backup "D:\工作台数据\backups\upgrade-具体时间"
```

必须先停止服务；新版包内目录锁会拒绝与运行中的服务同时恢复。早期没有目录锁的候选包仍需人工确认服务已经退出。工具只接受所选数据目录backups下的具体备份，检查SQLite完整性，先把当前数据库与会话保留到before-restore目录，再恢复旧状态。原表、图片、授权和缓存留在原位。恢复失败会还原操作前状态，恢复报告注明来源与保留位置。

当前迁移为新增表结构；旧版本对新表不会读写，但正式回退仍以恢复对应备份为准。旧会话恢复失败时程序会明确报迁移阻塞，不静默新建替代会话。恢复工具执行前应明确源备份和目标数据目录。

更新提示需设置真实可访问的HTTPS发布清单地址。没有地址的构建必须标为“更新入口待配置”，不能宣称已提供在线更新。

新任务会冻结完整视觉、填表和文字提取提示词及模型服务标识。暂停后若服务地址变化，需重新提出执行方案。早期任务缺少完整冻结提示词时，不静默套用新版提示词续跑：标签任务从失败项生成修复提案，文字底稿重新安排提取。旧结果保留。缓存键新增提示词和服务身份后，旧缓存可能需要重建，这不代表重新打标已保存的正式结果。
