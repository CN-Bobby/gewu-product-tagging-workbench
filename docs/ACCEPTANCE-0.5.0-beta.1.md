# 0.5.0-beta.1 验收记录

状态：候选构建中。正式8765仍运行0.4.0；本文只记录当前提交及其后生成候选包的证据。

## 已实现

- 四种结果形态和确定性尺码解析。
- 逐列`targets`、不可变`repair_scope_id`、兼容修订保留和语义修订失效。
- 新任务或人工修改接管失败单元格后，旧任务自动收尾。
- 商品标识统一解析，SKU数值0回退到父ASIN；原始0保留。
- 任务标题与滚动列表分离，按钮换行且点击高度不低于32px。
- 自动视觉和图文联合标签默认开放；每件商品只使用一张主图，补充套图只供高清人工核对。
- 标签构思可按每组6张主图比较最多24件代表样本；正式填表仍按每批5件执行，失败格式只重试对应商品并复用视觉观察。
- 在线更新入口移除，采用离线安装包与SHA256校验。
