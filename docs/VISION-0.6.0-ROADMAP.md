# 单主图视觉机制与后续增强

状态：基础机制纳入0.5.0-beta.1；自适应补样、局部裁剪和金标准自动统计保留为后续增强。

## 输入边界

每件商品的一张主图是完整且可独立执行的视觉输入。ASIN套图只作为可选补充证据，缺失套图不能阻止款式识别，也不能把其他商品的图片当作当前商品细节。

## 全局校准

1. 当前Beta按图片指纹稳定抽取最多24件代表商品；结合销量和文字字段的分层抽样属于后续增强。
2. 当前Beta每组比较6个不同商品的主图，提取可见款式差异、候选类别和边界反例。
3. 候选款式少于3个代表样本，或未归类／低置信结果超过10%，继续补样；总量最多60件。
4. 60件后仍不能覆盖时，生成全量扫描提案，先展示图片数、请求数和Token估算，再由用户确认。
5. 用户确认后冻结数据集视觉标准；后续标签任务引用该标准的不可变修订。

## 填表与疑难处理

正式填表保持每批5件商品，每件默认仅传一张主图。疑难商品进入4至6件的局部比较，可附已确认标准样本和当前主图裁剪。局部修复只包含明确选中的单元格，不自动扩大为整列或全量商品。

分别缓存全局标准、主图观察、局部裁剪和最终结果。每类缓存记录输入指纹、模型、提示词修订、请求数、等待时间、命中和失败位置。

## 开放门槛

用人工标注泳衣样本作为金标准，对比旧单图方案与当前单主图分组方案。发布证据必须报告准确率、严重幻觉、未知与否定边界，以及首次运行和缓存复用；未覆盖的复杂结构明确列为已知限制。
