# beta.5 简明测试清单

1. 安装前关闭旧工作台，保存桌面文件旁的 SHA256；运行安装程序并继续使用原数据目录。
2. 上传表格后不点击欢迎区三个示例，直接输入问题；分别测试多选、自由文字和“跳过问题并继续”。
3. 新建两个对话，在各自输入草稿、选择模型并上传图片；切换和刷新后确认内容、图号不串线。
4. 用按钮、剪贴板和拖入各上传图片，尝试只发图片及“比较图1、图2”；将一张图明确绑定到商品。
5. 在模型设置中保存两个具名Key，手动切换文本与视觉模型；确认页面只显示掩码。
6. 接入一个已有人工标签列，保留非空值并只补空白；停用再恢复接管，导出确认仍只有一个原列。
7. 先抽样最多20件，再做批量；服装、水杯、多组件套装各记录误判、未知和用量。
8. 如需回退，先停止工作台，安装归档 beta.4，再用升级前备份恢复数据库与 `datasets`。

问题反馈请同时记录：版本号、发生时间、工作表、对话名、操作顺序和界面技术详情；不要提交完整Key。
