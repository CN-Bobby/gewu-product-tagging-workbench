# 0.5.0-beta.2 验收记录

> 历史结论更新：后续客户图形安装发现目录验证会把首次安装误判为升级，本候选已停止分发并由0.5.0-beta.3取代。本页保留当时证据，不再作为可分发结论。

状态：本机候选验收通过；外部干净Windows 10/11 x64安装验收仍待完成。后续为保留用户指定的可用历史源码，已追溯创建 `v0.5.0-beta.2` 源码标签，指向归档构建的确切源码提交。该标签不是GitHub Release，不改变本页记录的验收状态。本文记录源码、安装包和隔离测试数据的证据；未改写用户正式商品数据。

## 已实现

- 四种结果形态和确定性尺码解析。
- Reasonix业务问题网页桥接、稳定错误分类、提案分组去重和业务讨论展示。
- 逐列`targets`、不可变`repair_scope_id`、兼容修订保留和语义修订失效。
- 新任务或人工修改接管失败单元格后，旧任务自动收尾。
- 商品标识统一解析，SKU数值0回退到父ASIN；原始0保留。
- 任务标题与滚动列表分离，按钮换行且点击高度不低于32px。
- 自动视觉和图文联合标签默认开放；每件商品只使用一张主图，补充套图只供高清人工核对。
- 标签构思可按每组6张主图比较最多24件代表样本；正式填表仍按每批5件执行，失败格式只重试对应商品并复用视觉观察。
- 在线更新入口移除，采用离线安装包与SHA256校验。

## 对话交互收尾证据

- 数据库结构升级为7；隔离迁移测试确认升级前生成`before-v7-*.db`一致备份，旧运行消息转为中断，旧提案补齐分组，迁移记录写入7。
- 真实Reasonix 1.25.1的业务问题使用`ask-*`工具调用和`kind=other`；网页只回传原请求的`optionId`。实际选项字段同时兼容其大写`Label/Description`格式。
- 问题固定单选，最多3题、每题2至3个互斥选项。异常多选或结构无效的问题显示为不支持的问题，不归为模型服务故障。
- Shell、文件写入及子任务权限保持关闭；非Ask权限请求会显示实际工具名和拒绝原因。
- 真实证据保存在隔离目录`storage/release-verification/chat-v7-*/evidence/real-ask-bridge-report.json`，不包含客户数据。
