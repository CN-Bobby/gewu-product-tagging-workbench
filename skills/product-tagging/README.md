# 商品标签工程 0.1.0

主文件讲判断方法，references 是按需规范，examples 是明确标识的测试案例。工作台通过 backend/tagging_rules.py 读取唯一源，核心指令注入 Reasonix；read_tagging_rules 只读加载参考。不是依赖 CLI 自动发现的全局安装包，不修改用户其他项目配置。

确认的定义保存判断规则与 Skill 版本。执行任务保存完整规则快照、哈希和定义修订；直接模型调用使用该快照。文字底稿拥有独立任务、缓存和证据，新增标签仍需人工确认。

验证先记录基线，再运行加载后的相同场景及新压力案例。基线报告诚实区分代理评测与真实模型测试，结构校验缺陷与语义失败分别记录。测试均使用隔离库，未经人工审核的模型标签不称为已人工确认。

升级：修改源文件并升级 manifest 版本，重启工作台恢复原 Reasonix 会话；旧执行快照不变。新数据库结构写入迁移版本3，迁移前备份；回滚须停止服务并按项目恢复脚本恢复完整备份，同时恢复旧程序，不能直接删除单表。
