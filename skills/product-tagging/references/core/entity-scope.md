# 实体与结论范围

先列实体，再判属性。实体角色至少区分：`primary_product` 主商品、`component` 组成件、`included_accessory` 随附配件、`variant_reference` 变体示意、`demo_object` 演示物、`person_environment` 人物/环境、`package` 包装、`text_graphic` 文字图标。记录部件关系、安装/包含关系和可见区域。标签必须声明 target scope；不得把手机、汽车、模特、饮料、清洁刷或包装颜色归到主商品。结论层级固定为 image / product / dataset_standard / cell_result，低层证据不能无校准升级为高层结论。
