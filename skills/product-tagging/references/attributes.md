# 单属性、多个属性与三态

最初使用种类列，单元格填命中属性。一次结果允许完整保存明确命中集合及逐属性证据。

若同一商品明确同时命中多个属性，提出整类拆列。确认之前展示待确认，不丢弃多值；确认之后整张表统一使用“种类－具体属性”。类别与属性身份稳定，新增属性也需要提案，不自动缩回单列。

内部属性值 true→✓，false→❌，null→空白。true 要有命中证据；false 要有足够的排除证据，例如明确“无条纹”，或按已确认规则完整观察可排除；单纯没提到只能 null。失败、未处理、未知、待更新是另外的执行状态，不以 false 代替。

旧单值“花卉”迁移只给花卉 true；条纹等先 null，除非原证据充分否定。旧人工修正沿用其来源，后台不能覆盖执行开始后发生的修改。

“花卉和条纹同时存在”→两个 true；“花卉或条纹，图像不清楚”→null 和不确定原因，不触发拆列。对类别限定“主色、唯一主用途”的定义，不把辅助色或次用途误当第二命中；先按定义边界判断。
